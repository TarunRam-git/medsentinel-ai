# Project image

`public/og.png` is the project sharing card and README artwork. It was generated with the built-in Imagegen tool and checked for correct wording. The prompt was:

> Create a single finished landscape social sharing card for MedSentinel AI. Exact text: “MedSentinel AI”, “A clearer view of safer care.”, and “Clinical integrity research”. Clean editorial digital design; warm off-white #f5f7fa, restrained sage #e6f5f1, dark teal #087f79, dark ink #152b39. Large sans-serif headline on the left, three evidence cards connecting to a shield on the right. Generous space, fine borders, minimal clinical dashboard aesthetic. No photos, human figures, additional words, invented metrics, or clinical-validation claims.

The app uses Lucide icons and DM Sans/Manrope typography with system-font fallbacks. The image is not used to represent research results or patient data.
